# FlashAI — Your Personal AI Assistant 🚀

FlashAI is a modern AI-powered chatbot web application that allows users to interact with an intelligent assistant in multiple conversational moods such as normal, funny, sad, and angry. Built with a scalable full-stack architecture using Next.js for the frontend and FastAPI for the backend.

🔗 **Live Demo:** https://flash-ai-dun.vercel.app/

---

## 🌟 Features

- 🤖 AI-powered intelligent responses  
- 🎭 Multiple chat moods (normal, funny, sad, angry)  
- 💬 Clean, responsive, and user-friendly UI  
- ⚡ Fast performance with optimized API calls  
- 🔄 Real-time conversational experience  

---

## 🛠️ Tech Stack

**Frontend:**
- Next.js
- React
- Tailwind CSS

**Backend:**
- FastAPI (Python)
- REST APIs for AI communication

**Deployment:**
- Frontend: Vercel  
- Backend: Render

## 🚀 Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/flashai.git
cd flashai

Install dependencies (Frontend - Next.js)

cd frontend
npm install
npm run dev

Setup Backend (FastAPI)

cd backend
pip install -r requirements.txt
uvicorn main:app --reload
